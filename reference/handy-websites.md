# Handy Websites

Everything here is GitHub Copilot or VS Code. Links to other AI products have been left out on
purpose — this is a Copilot course, and several of those domains are blocked on the Rabobank
network anyway.

## Official documentation — start here

- [Customize Copilot with instructions](https://code.visualstudio.com/docs/copilot/customization/custom-instructions) — how `copilot-instructions.md` works
- [Custom agents](https://code.visualstudio.com/docs/agent-customization/custom-agents) — the `.github/agents/*.agent.md` files you built in Exercise 3
- [Prompt files](https://code.visualstudio.com/docs/agent-customization/prompt-files) — saved prompts you trigger with `/name`
- [Agent skills](https://code.visualstudio.com/docs/agent-customization/agent-skills) — knowledge packs Copilot pulls in by itself
- [About agent skills — GitHub Docs](https://docs.github.com/en/copilot/concepts/agents/about-agent-skills) — the concept explained
- [VS Code Copilot features cheat sheet](https://code.visualstudio.com/docs/copilot/reference/copilot-vscode-features) — the authoritative list of `@`, `#` and `/`
